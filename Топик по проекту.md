## Docker-ы

```
├── compose
│   └── docker-compose.yml
├── docker
│   ├── gazebo
│   │   └── Dockerfile
│   └── navigation
│       └── Dockerfile
```

Папка docker содержит файлы необходимые для поднятия докера.

Докер поднимается по инструкции описанной в docker-compose.yml.

Необходимые для каждого докера зависимости расписаны в Dockerfile в соответствующих файлах.

## Скрипты запуска докеров

Скрипты:
- `run_dockers.sh` — поднимает два докера
- `stop_dockers.sh` — останавливает два докера

# Запуск проекта

Проект запускается через скрипт:

```bash
./run_dockers.sh
```

Запускаются докеры. Чтобы в них войти:

**Вход в докер с Gazebo:**
```bash
docker exec -it ros2_gazebo_runtime bash
```

**Вход в докер с навигацией:**
```bash
docker exec -it ros2_navigation_runtime bash
```

Для выхода — `exit`.

## Варианты запуска симуляции

### 1. Через скрипты

**В Gazebo-докере:**
```bash
/src/scripts/spawn_robot.sh
```

**В navigation-докере:**
```bash
./run_navigation.sh
```

(Скрипт `source_ros2.sh` выполняется автоматически при запуске навигации, но при необходимости можно вызвать отдельно.)
